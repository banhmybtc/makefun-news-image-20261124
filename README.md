# makefun-news-image-20261124

One image summing up the world's news of Tuesday 24 November 2026, as a
newspaper front page: Kyiv defends the sinking of a Russian warship off
Libya; a Houthi drone hits Riyadh's PIF Tower again; a suspected North
Korean aircraft breaches South Korean airspace near Ulleung; Hamas's
security chief is killed in a Gaza strike; Trump tells the reinstated
Nvidia chief to tell Congress the truth; and Tajikistan starts quitting
the ICC.

## How it works

`entry.png` (1024x1024) is the front page, drawn with Pillow by a script
in the build workspace. `main.py` (Python 3.13, standard library only)
copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`, byte for byte, so both
grading runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
